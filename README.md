
# Python Simple Calculator

A beginner-friendly Python project featuring
a command-line calculator and a graphical
calculator built with Tkinter.

## About the Project

This project was developed to practice Python
programming fundamentals and basic GUI development.

## Features

### Command-Line Calculator
- Addition, subtraction, multiplication, division
- Modulus and power operations
- Calculation history
- Input validation and error handling

### GUI Calculator
- Interactive calculator interface
- Clickable number and operation buttons
- Basic arithmetic calculations
- Clear button
- Error handling

## Technologies Used

- Python 3
- Tkinter
- Visual Studio Code
- Git and GitHub

## Project Structure

python-simple-calculator/
- calculator.py
- gui_calculator.py
- README.md
- screenshots/

## How to Run

### 1. Command-Line Calculator

```bash
python calculator.py
```

### 2. GUI Calculator

```bash
python gui_calculator.py
```
